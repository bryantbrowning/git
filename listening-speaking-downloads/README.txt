UNLOCK 2 · LISTENING & SPEAKING · UNITS 2–4

START HERE
1. Download and extract Unlock_LS_Units_2-4_12_Lessons.zip.
2. Open index.html in a modern browser.
3. Choose a lesson. Everything needed for the classroom task stays inside its presentation.

CONTENTS
12 individual HTML presentations;258 timed activity canvases;90 minutes each;6 Teach the Document assignments. Each has its own design, source alignment, language practice, short listening input, speaker/listener roles, sustained performance, feedback and replay. The teacher guide gives every 90-minute plan, original listening key and facilitation procedure. Six text briefs include worked TTD examples. The course map and source alignment identify the printed textbook pages.

CONTROLS
Task / Book / Listen / Language / TTD / Teacher stay on the current slide.
Book source buttons enlarge a page within the same presentation; Escape closes it.
Arrows navigate; Next reveals cues before moving on where indicated.
B=Book, T=TTD, N=Teacher. Focus / Full screen support projection.
The timer can time a turn or the entire activity; it does not advance slides automatically.

SAVING
Cue notes and TTD checks are stored per two-lesson pair in the same browser when available. Save copy exports editable JSON; import it into the next lesson of that pair. Exports are the dependable backup and cross-device route. Wrong-pair or Reading & Writing files are rejected without replacing current work. Local-file browser storage can vary.
Optional microphone recording stays in the open page. Download a take before closing. It is not uploaded or automatically included in cue-note exports.

LISTENING
Each lesson includes a complete original teacher-read script with separate questions and answers. Optional local English browser speech is available if the device supplies a suitable voice. You can choose licensed local audio/video to play inside the canvas. Publisher recordings are not included; the publisher route is identified, and its book questions must be used with its own recording.

TTD
Launch in Lessons 1/3; submit at the following lesson's start. One 3–5-minute English recording, explaining a genuine readable document from short cues. Teach 3–5 useful terms and 3–5 ideas; show evidence, ask at least two comprehension questions, evaluate/limit, summarize and credit. Use the instructor's calendar and submission route. The provided model extracts are short worked examples, not full-length submissions.

PRINTING
Teacher contains print controls for private A/B cards, lesson/listening sheets and TTD briefs/plans. Notes can also be printed. Printing is optional; the same teaching materials are embedded.

DELIVERY
These are HTML browser presentations, not native PowerPoint files. Fonts, images, text and scripts are embedded for classroom use without website access. Optional local media must be reselected after reopening. The cloud browser test used a local HTTP preview because its policy blocks direct file:// navigation; no external classroom requests were made. Normal browser/file permissions determine optional microphone and storage behavior.

The previous Reading & Writing course remains separate. The original Unit 1 guides are preserved unchanged in the working reference folder. The interface prototype is not included or counted as a new lesson.
