# Unlock Units 2–4: 12 reading and writing lessons

The ZIP contains 12 standalone HTML presentations, four 90-minute lessons per unit, with a writing focus and six Teach the Document assignments. It includes the course library, teacher guide, course map, assignment briefs and models, and embedded textbook reference pages.

1. Download **Unlock_Units_2-4_12_Lessons.zip** from this folder.
2. Extract the ZIP on your computer.
3. Open **index.html** inside the extracted **Unlock_Units_2-4** folder.
4. Select a lesson. The presentations work offline in a browser.

This folder provides downloadable files; it does not publish a website.
